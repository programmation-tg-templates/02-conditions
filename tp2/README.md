# TP2 — Casse d’une lettre

**Objectif** : distinguer une majuscule, une minuscule et une valeur invalide à l’aide de conditions.

## Consignes

Complétez dans `tp2.ts` le corps de `verifierLettre` selon la valeur reçue.

Ne modifiez pas le nom, le paramètre ou le type de retour de la fonction.

## Tester votre code

Lancez `npm test -- tp2`, puis `npm run typecheck`.

## Soumettre sur INGInious

Ouvrez la tâche « TP2 — Casse d’une lettre » et complétez le corps de fonction.
