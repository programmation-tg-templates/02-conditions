# TP4 — Appréciation d’une note

**Objectif** : sélectionner une appréciation selon plusieurs intervalles et reconnaître une valeur invalide.

## Consignes

Complétez dans `tp4.ts` le corps de `donnerAppreciation` pour retourner l’appréciation correspondant à la note reçue.

Ne modifiez pas le nom, le paramètre ou le type de retour de la fonction.

## Tester votre code

Lancez `npm test -- tp4`, puis `npm run typecheck`.

Ouvrez la tâche « TP4 — Appréciation d’une note » et complétez le corps de fonction.
