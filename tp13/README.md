# TP13 — Jour du week-end

**Objectifs** :

- Combiner deux comparaisons avec `||`.
- Répéter la variable dans chaque comparaison.

## Consignes

Les jours du week-end sont `samedi` et `dimanche`, écrits en minuscules.

Écrivez la condition qui fait retourner `true` pour un jour du week-end.

Exemples :

- `estWeekend("dimanche")` retourne `true`.
- `estWeekend("mardi")` retourne `false`.

Sur INGInious, la signature, le `if` et les deux `return` sont fournis : vous écrivez seulement la condition, entre les parenthèses du `if`, sans point-virgule.

Un agenda ou une boutique en ligne adapte ses horaires et ses tarifs selon le jour.
