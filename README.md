# 02 — Conditions

Exercices TypeScript sur les structures conditionnelles du cours de programmation (BAC1 techniques graphiques).

## Installation

```bash
npm install
```

## Travailler sur un exercice

Chaque dossier `tdN/`, `tpN/` ou `defiN/` contient le fichier TypeScript, les tests écrits par l’enseignant et les consignes.

Lancez les tests d’un exercice avec `npm test -- td1`, `npm test -- tp7` ou `npm test -- defi1`.

Vérifiez que votre code respecte les types avec `npm run typecheck`.

Pour les exercices où la fonction est à écrire en entier, le fichier TypeScript ne contient qu’un commentaire : la consigne décrit en français le nom, les paramètres et le type de retour de la fonction.
Écrivez `export` devant `function`, pour que les tests puissent l’importer.

Les exercices du TP3 sont dans le dépôt `03-logique-booleenne`.

## Soumettre

Ouvrez la tâche correspondante sur INGInious.
Selon l’exercice, le champ de réponse contient :

- une condition à compléter dans un `if` fourni ;
- le corps de la fonction, dont la signature est fournie ;
- la fonction complète, à écrire à partir de la description de la consigne ; le champ est vide.

N’écrivez pas `export` dans INGInious : la correction l’ajoute elle-même.
