# 02 — Conditions

Exercices TypeScript sur les structures conditionnelles du cours de programmation (BAC1 techniques graphiques).

## Installation

```bash
npm install
```

## Travailler sur un exercice

Chaque dossier `tdN/` ou `tpN/` contient le fichier TypeScript à compléter, les tests écrits par l’enseignant et les consignes.

Lancez les tests d’un exercice avec `npm test -- td1` ou `npm test -- tp1`.

Vérifiez que votre code respecte les types avec `npm run typecheck`.

## Soumettre

Ouvrez la tâche correspondante sur INGInious et complétez uniquement le ou les corps de fonction demandés.

Les signatures et les tests sont fournis automatiquement et ne doivent pas être recopiés.
